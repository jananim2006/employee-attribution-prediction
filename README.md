# Employee Performance Prediction

## Project Overview

This project uses **Logistic Regression** to predict whether an employee is a **High Performer** based on selected employee-related features.

The model uses employee experience, skill score, training hours, and peer feedback as input features.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Machine Learning Model

**Logistic Regression**

## Features Used

* Experience
* Skill Score
* Training Hours
* Peer Feedback

## Target Variable

**High Performer**

The target variable represents whether an employee belongs to the high-performance category.

## Project Workflow

1. Load the employee dataset using Pandas.
2. Select relevant features.
3. Separate the input features and target variable.
4. Standardize the features using `StandardScaler`.
5. Split the data into training and testing sets.
6. Train the Logistic Regression model.
7. Make predictions on the test data.
8. Evaluate the model using accuracy, classification report, and confusion matrix.
9. Visualize the confusion matrix using Seaborn.

## Evaluation Metrics

The model is evaluated using:

* Accuracy
* Classification Report
* Confusion Matrix
